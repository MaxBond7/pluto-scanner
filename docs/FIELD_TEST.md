# Полевой тест: что нужно

Цель — проверить реальную дальность, ложные тревоги и собрать размеченные
записи для ML. Безопасно и без передачи на дальние дистанции.

## Что взять

- Pluto + USB-кабель + ноутбук.
- Антенна(ы), которые реально будешь использовать.
- Power bank для Pluto, если нет розетки.
- Wi-Fi роутер 2.4 ГГц + питание.
- Телефон/ноутбук, который создаст трафик через роутер.
- Рулетка или GPS-телефон для расстояний.
- Блокнот/таблица для заметок.
- Baofeng — только для короткого теста с аттенюатором/эквивалентом
  нагрузки, не для передачи на километры.

## Подготовка

1. Поставь роутер на фиксированный канал 2.4 ГГц (например, 6 → 2437 МГц).
2. Pluto — на высоту 1–1.5 м, антенна вертикально, не меняй её положение
   между точками.
3. В приложении:
   - усиление 40 дБ;
   - полоса 20.48 MS/s (если стабильно) или 10.24 MS/s;
   - порог 8 дБ;
   - тревога: 3 подтверждения, 70%;
   - белый список пока не включай.
4. Создай папку для теста, например `Z:\FieldTest_20261101\`.

## Точки замера

Для каждой дистанции: **5, 10, 20, 50, 100 м** (дальше — если есть прямая
видимость).

На каждой точке:

1. Включи генерацию Wi-Fi-трафика: ping/скачивание/видео через роутер.
2. Запусти **«Дрон-монитор»**, полоса 2.4 ГГц, 15 секунд.
3. Сохрани скриншот и `summary.json` (кнопка «Журнал» / папка `drone_logs`).
4. Запиши IQ 0.5–1 секунды:
   - вкладка «Запись IQ»;
   - центр 2437 МГц;
   - полоса 20.48 MS/s (или 10.24);
   - метка `WIFI`.
5. Запиши в таблицу:
   - расстояние;
   - прямая видимость/стена/дерево;
   - усиление;
   - полоса;
   - сколько событий и тревог;
   - примерный уровень сигнала.

## 433 МГц / Baofeng

Только если это разрешено в твоём регионе и только на малой мощности.

1. Аттенюатор 20–30 дБ + эквивалент нагрузки или очень короткая антенна.
2. Расстояние 1–3 м, не больше.
3. Запись IQ 2 секунды, полоса 2.048 MS/s, метка `NARROW`.
4. Не передавай на частотах служб, аварийных и авиационных.

Если сомневаешься в legality — пропусти этот пункт. Для ML хватит Wi-Fi.

## Что прислать мне

Скопируй в одну папку:

```text
Z:\FieldTest_20261101\
  drone_logs\        # summary.json и события
  iq_recordings\     # .cf32 + .json с метками
  notes.txt          # расстояния, препятствия, антенна, усиление
```

Или просто скажи путь к папке. Я:

- импортирую записи;
- обучу модель на реальных данных;
- сравню detection rate и ложные тревоги по дистанциям;
- подготовлю отчёт и, если нужно, поправлю пороги/признаки.

## Ограничения

- Wi-Fi — не дрон, но хороший безопасный источник для проверки дальности.
- 1.5 км на роутере не будет; это тест тракта и детектора, не реклама.
- Baofeng не заменяет дрон-линк и не даёт легальную дальнюю передачу.
- Один Pluto не даёт пеленг.
