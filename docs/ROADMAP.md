# Roadmap

## Сделано

- Спектр, водопад, VFO, wobble, AM/FM/SSB/CW.
- Контакты и известные частоты.
- Сканер 325 МГц – 3.8 ГГц, JSON-фон, сравнение.
- Дрон-монитор 433/868/915 МГц, 1.2–1.3 / 2.4 / 5.8 ГГц.
- Строгие тревоги, журнал событий.
- IQ-клипы, карточка события, экспорт.
- Локальная библиотека сигнатур и top-3 гипотезы.
- 64 автотеста, симулятор и реальные Pluto+.

## Ближайшее

1. Белый список и обучение фону:
   - запоминать постоянные Wi-Fi/Bluetooth;
   - профили фона по антенне и усилению;
   - меньше ложных тревог.
2. Ethernet для двух Pluto+:
   - автопоиск;
   - health-мониторинг;
   - стабильные 20.48 MS/s на каждом.
3. Второй RX-канал Pluto+:
   - две полосы/антенны одновременно;
   - эксперименты с фазовым пеленгом.
4. Remote ID через Wi-Fi/BLE-адаптер.
5. Запись IQ более длинными фрагментами и воспроизведение через DSP.

## Дальше

- ML-классификатор по размеченным IQ/спектрограммам.
- RSSI/фазовый пеленг на когерентной паре.
- Карта и журнал с GPS.
- Headless/web-режим и Telegram-уведомления.
- Калибровка в dBm.
- Установщик и автообновление.

## Принципы

- Только пассивный приём.
- Не обещать модель/направление/дальность без соответствующего железа.
- Любая гипотеза должна иметь confidence и ссылку на источник.
- Сначала измеримая ценность, потом «умные» обещания.
