# ML за 5 шагов

Простая инструкция: как включить ML, записать примеры, поставить метки и
дообучить модель. Без терминала и без программирования.

## Шаг 0. Что скачать

Скачай **установщик** `PlutoScanner-Setup-*.exe` со страницы
[Releases](https://github.com/MaxBond7/pluto-scanner/releases).

Можно и portable ZIP: распакуй и запусти `PlutoScanner.exe`.

Python не нужен.

## Шаг 1. Запустить и подключить Pluto

1. Подключи Pluto по USB.
2. Запусти Pluto Scanner.
3. Нажми **«Найти»**, выбери `usb:...` и **«+ Pluto»**.
4. Убедись, что в списке устройств статус **«работает»**.

Если Pluto нет — нажми **«+ Симулятор»**, чтобы потренироваться без железа.

## Шаг 2. Записать примеры сигналов

Открой вкладку **«Запись IQ»**.

Для каждого типа сигнала:

1. Настройся на частоту сигнала.
2. Поставь длительность 5–10 секунд.
3. Нажми **«Начать запись»**.
4. Повтори 5–10 раз для каждого класса.

Что можно записывать для тренировки:

| Что рядом | Какую метку ставить |
|---|---|
| Wi-Fi роутер | `WIFI` |
| Baofeng / узкая FM-речь | `NARROW` |
| Аналоговая камера / FPV | `VIDEO_ANALOG` |
| Цифровое видео / Wi-Fi камера | `VIDEO_DIGITAL` |
| Пульт / телеметрия | `TELEMETRY` |
| Скачкообразный пульт | `FHSS` |

Не передавай в эфир без разрешения. Для тестов используй малую мощность,
эквивалент нагрузки или аттенюатор.

## Шаг 3. Поставить метки

1. В таблице записей выбери запись.
2. В строке **«Метка»** выбери класс.
3. Нажми **«Сохранить метку»**.

Можно и по-другому: открой событие в дрон-мониторе и нажми
**«ML ошибся? Указать класс»**. IQ-фрагмент сам сохранится как пример.

## Шаг 4. Обучить

1. Открой вкладку **«ML»**.
2. Нажми **«Обучить на записях»**.
3. Подожди 10–40 секунд.
4. Смотри результат:
   - источник `real` или `mixed`;
   - точность;
   - сколько реальных и синтетических блоков.

Модель сохранится в папке данных:

- установленная версия: `%LOCALAPPDATA%\PlutoScanner\user_data\ml_model.json`;
- portable: рядом с `PlutoScanner.exe`.

После этого новые события получат строку **ML-гипотеза**.

## Шаг 5. Проверить и улучшить

1. Запусти **«Дрон-монитор»**.
2. Открой событие.
3. Если ML ошибся — нажми **«ML ошибся? Указать класс»**.
4. Вернись в **«ML»** и снова нажми **«Обучить на записях»**.

Повторяй: чем больше исправлений, тем лучше модель под твою антенну и место.

## Где что лежит

| Что | Где |
|---|---|
| Модель | `user_data/ml_model.json` |
| Записи IQ | `iq_recordings/` |
| Исправления ML | там же, с меткой и пометкой `ML feedback` |
| Журнал дронов | `drone_logs/` |
| Лог приложения | `pluto_scanner.log` |

Для установленной версии всё это в `%LOCALAPPDATA%\PlutoScanner`.
Для portable — рядом с `.exe`.

## Если что-то не работает

**«Нет IQ-фрагмента»**
В дрон-мониторе включи **«Писать IQ-фрагмент для событий»**.

**«Мало записей для отложенной выборки»**
Добавь ещё записи. Минимум 2 записи на класс, лучше 10.

**ML не влияет на тревогу**
Так и задумано: тревогу решает эвристика, ML — вторая гипотеза.
Белый список и пороги тревог остаются отдельно.

**Модель всё путает**
Проверь метки, добавь примеры, обучи заново. Синтетическая модель — только
стартовый baseline, не гарантия на реальном эфире.

## Чего ML не делает

- не определяет модель дрона;
- не декодирует протокол;
- не заменяет Remote ID;
- не даёт дальность 1.5 км;
- не работает без IQ-примеров лучше, чем эвристика.

## Внешние датасеты

Если есть готовый SigMF/raw IQ датасет, используй в «Запись IQ» кнопку
**«Импорт…»**. Подробнее — `docs/DATASETS.md`.
