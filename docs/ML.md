# ML-классификатор

## Что это

Вторая гипотеза к эвристике дрон-монитора. Модель смотрит на те же
измеренные признаки IQ, что и обычный классификатор, и выдаёт top-3 класса
с вероятностями.

**Она не заменяет эвристику и не определяет модель дрона.** В таблице и
карточке события основным остаётся эвристический класс, а ML показывается
рядом как дополнительная гипотеза.

## Классы

- `FHSS` — скачкообразное управление;
- `TELEMETRY` — телеметрия / пульт;
- `VIDEO_ANALOG` — аналоговое видео;
- `VIDEO_DIGITAL` — цифровое видео;
- `WIFI` — похоже на Wi-Fi;
- `NARROW` — узкополосная активность.

## Признаки

Модель использует 12 чисел из `DroneObservation`:

| Признак | Смысл |
|---|---|
| `log10_bw_hz` | занятая ширина |
| `log10_snr_db` | отношение сигнал/шум |
| `active_fraction` | скважность |
| `log10_bursts` | число посылок |
| `log10_burst_rate` | частота посылок |
| `log10_median_burst_ms` | типичная длительность |
| `log10_max_burst_ms` | максимальная длительность |
| `flatness` | «плоскость» спектра |
| `peak_to_mean_db` | пик к среднему |
| `busy_fraction` | занятость полосы |
| `bw_fraction` | ширина / полоса захвата |
| `burst_shape` | median / max длительность |

Это компактный и объяснимый набор, а не «чёрный ящик» на сырых IQ.

## Модель

Softmax-регрессия на NumPy:

- стандартизация признаков;
- Adam-оптимизация;
- L2-регуляризация;
- top-3 вероятности;
- JSON-файл `user_data/ml_model.json`.

Никаких сетевых запросов и облака. Обучение и вывод — локально.

## Из коробки

В сборку входит `assets/ml_model_default.json` — синтетическая модель,
обученная нашим генератором. Если пользователь ещё ничего не обучал, ML-вкладка
и карточка события работают сразу.

Это **не** обещание точности на реальном эфире: модель показывает вторую
гипотезу и честно помечает источник `synthetic`. После разметки своих записей
её можно заменить локальной моделью.

## Разметка записей

1. Запишите IQ во вкладке **«Запись IQ»**.
2. Выберите запись в таблице.
3. В строке **«Метка»** выберите класс и нажмите **«Сохранить метку»**.
4. Повторите для нескольких записей каждого класса.

Метка хранится в JSON рядом с `.cf32`. Записи без метки в обучении не
участвуют.

## Обучение на реальных записях

```powershell
# Только размеченные записи
.\.venv\Scripts\python.exe -m pluto_scanner.ml.train `
  --real-dir iq_recordings --no-synthetic --out user_data\ml_model.json

# Реальные записи + синтетика для баланса
.\.venv\Scripts\python.exe -m pluto_scanner.ml.train `
  --real-dir iq_recordings --out user_data\ml_model.json
```

Или во вкладке **ML** → **«Обучить на записях»**.

Важно:

- блоки режутся по 0.2 с, до 20 блоков на запись;
- тихие блоки отбрасываются;
- проверка идёт **по записям**, а не по отдельным блокам, чтобы один и тот же
  сигнал не попал одновременно в train и test;
- если записей меньше двух на класс, отложенной выборки нет — интерфейс
  честно пишет «на обучении — мало записей»;
- синтетика добавляется только для баланса классов; в метаданных видно,
  сколько реальных и синтетических блоков использовано.

## Обучение на синтетике

Генератор создаёт шесть классов IQ:

- узкополосную несущую;
- 2-FSK телеметрию с посылками;
- FHSS со случайными хопами;
- аналоговое видео с гауссовым спектром;
- цифровое видео с прямоугольным спектром;
- Wi-Fi-подобные широкополосные посылки.

Запуск:

```powershell
.\.venv\Scripts\python.exe -m pluto_scanner.ml.train `
  --per-class 60 --epochs 600 --out user_data\ml_model.json
```

Или во вкладке **ML** → **«Обучить на синтетике»**.

Текущий baseline:

- 360 синтетических блоков (60 на класс);
- точность на отложенной выборке: **94.4%**;
- согласие с эвристикой: **25.8%**.

Цифры относятся только к синтетике. Они не доказывают качество на реальном
эфире.

## Как это выглядит

- Вкладка **ML** показывает модель, точность, precision/recall по классам и
  процесс обучения.
- В карточке события появляется строка:
  `ML-гипотеза: NARROW 93% · ещё: FHSS 5%, TELEMETRY 2%`.
- В JSON события сохраняется блок `ml` с label, confidence и alternatives.

## Ограничения

- Синтетика ≠ реальный эфир: другая антенна, усиление, интермодуляция,
  многолучёвость.
- Модель не декодирует протокол и не определяет модель дрона.
- Классы — те же гипотезы, что и у эвристики; это не Remote ID.
- Для реального качества нужен размеченный датасет: записи IQ + метки
  «что это было» из независимого источника.
- Обучение на реальных записях уже поддерживается; качество зависит от
  количества и чистоты меток, а не от алгоритма.
- Текущая модель — честный baseline, а не обещание «ML всё решит».
