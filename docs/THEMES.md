# Темы оформления

## Что есть «с завода»

| Имя | Что это |
|---|---|
| `mono` | **По умолчанию.** Чистый чёрно-белый терминал, чёрный фон, острые углы, моноширинный шрифт |
| `mono-acid` | То же, но один редкий кислотно-зелёный акцент |
| `mono-ember` | Ч/б с огненно-оранжевым акцентом |
| `mono-ice` | Ч/б с холодным циановым акцентом |
| `classic` | Прежняя тёмно-синяя тема, для тех, кто привык |

Акцент используется **редко**: кривая спектра, выделенная вкладка, выбранный
элемент, тревога. Всё остальное — чёрное, белое и серое.

## Как переключить

1. **В окне:** внизу справа список **ТЕМА**.
2. **Из командной строки:** `python -m sdr_scanner --theme mono-ember`.
3. Выбор запоминается в `user_data/settings.json` и применяется при
   следующем запуске.

Внизу есть кнопка **папка** — она открывает каталог пользовательских тем.

## Своя тема

Положите `.json` в `user_data/themes/` (папка создаётся при первом запуске
вместе с `README.txt`). Тема появится в списке при следующем запуске.

```json
{
  "version": 1,
  "name": "my-theme",
  "title": "MY THEME",
  "description": "моя тема",
  "font": "Consolas",
  "radius": 0,
  "waterfall": "grey",
  "colors": {
    "bg": "#000000",
    "panel": "#000000",
    "panel_alt": "#0a0a0a",
    "input": "#080808",
    "hover": "#161616",
    "border": "#2a2a2a",
    "border_strong": "#6f6f6f",
    "fg": "#f2f2f2",
    "fg_dim": "#aaaaaa",
    "fg_muted": "#6e6e6e",
    "accent": "#ffffff",
    "accent_soft": "#c8c8c8",
    "ok": "#dcdcdc",
    "warn": "#ffffff",
    "danger": "#ffffff",
    "danger_bg": "#f2f2f2",
    "danger_fg": "#000000",
    "selection_bg": "#ffffff",
    "selection_fg": "#000000",
    "graph_bg": "#000000",
    "graph_fg": "#a0a0a0",
    "grid": "#1c1c1c"
  }
}
```

Обязательное поле только `name`. Недостающие цвета берутся из `mono`,
неизвестные ключи игнорируются.

### Токены

| Токен | За что отвечает |
|---|---|
| `bg` | общий фон окна |
| `panel` | фон групп, вкладок, таблиц |
| `panel_alt` | чередование строк, неактивные вкладки |
| `input` | поля ввода, списки |
| `hover` | наведение на кнопки |
| `border`, `border_strong` | рамки и разделители |
| `fg` | основной текст |
| `fg_dim` | подписи, вторичный текст |
| `fg_muted` | самый тихий текст |
| `accent` | главный акцент: заголовки групп, выбранная вкладка, кривая |
| `accent_soft` | мягкий вариант акцента |
| `ok`, `warn`, `danger` | состояния |
| `selection_bg`, `selection_fg` | выделение (инверсия) |
| `graph_bg`, `graph_fg` | фон и оси графиков |
| `grid` | сетка графиков |

### Шрифт, углы, водопад

- `font` — любое имя шрифта, например `"Consolas"` или
  `"Cascadia Mono"`. Для монохромных тем используется моноширинный.
- `radius` — радиус скругления в пикселях, `0` даёт острые углы.
- `waterfall` — карта цветов водопада из pyqtgraph: `"viridis"`, `"grey"`,
  `"inferno"` и другие. В монохромных темах — `grey`.

## Как это устроено

- `sdr_scanner/ui/themes.py` — движок: палитры, JSON, сборка QSS.
- Старый код писал цвета литералами (`#f87171`). Теперь они проходят через
  `tcol()` / `qss()` и переводятся в цвета активной темы. Поэтому новая тема
  не требует правок в виджетах.
- `set_style(widget, "...")` запоминает исходный шаблон, чтобы при смене
  темы перекрасить всё без перезапуска (`retint`).
- Графики отдельно перекрашиваются через `retheme()` — у них свои перья и
  карта цветов водопада.

## Ограничения

- Иконка приложения и системные диалоги Windows не темизируются.
- Карта цветов водопада — единственное место, где тема может выйти за
  ч/б; это сделано намеренно, чтобы сигнал было видно.
- Прозрачность и градиенты не поддерживаются: тема — это плоские цвета.
