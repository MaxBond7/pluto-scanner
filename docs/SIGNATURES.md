# Библиотека сигнатур

## Что это

Локальная SQLite-база типовых радиосигналов и открытых справочных данных.
Она помогает перейти от «похоже на FHSS» к списку возможных источников:
Wi-Fi, Bluetooth, Zigbee, RC-пульт, LoRa, FPV-видео, дрон-линк и т.д.

**Это не декодер протоколов и не определение модели дрона.** Совпадение —
гипотеза по измеренным признакам.

## Схема записи

| Поле | Смысл |
|---|---|
| `id` | стабильный идентификатор |
| `name` | человекочитаемое название |
| `category` | категория (Wi-Fi, Дроны, Телеметрия…) |
| `source_class` | класс источника для матчинга |
| `start_hz`, `end_hz` | типовой диапазон |
| `bw_hz` | типичная ширина |
| `modulation` | модуляция/форма |
| `duty` | типичная скважность |
| `burst_ms` | типичная длительность посылки |
| `hop` | `none` / `slow` / `fast` |
| `notes` | пояснение |
| `references` | открытые источники |
| `license` | условие использования |
| `confidence` | априорная уверенность |
| `builtin` | встроенная запись |

## Матчинг

Веса:

- диапазон — 45%;
- ширина — 25%;
- скважность — 15%;
- совместимость класса — 15%.

Дополнительно учитываются hop-профиль и априорная уверенность записи.
Если частота вне диапазона, score резко снижается. Результат — top-3 с
причинами совпадения.

## Источники

Встроенный каталог собран по открытым справочным материалам: таблицы
частотных allocations ITU/FCC/Ofcom, SigIDWiki, RadioReference, открытые
описания Wi-Fi/BLE/Zigbee, FPV-видео и дрон-линков.

Для каждой записи указан источник и лицензия. Не добавляйте:

- закрытые/коммерческие базы;
- данные, полученные без разрешения;
- утверждения «это точно модель X» без декодирования/Remote ID/датасета.

## Добавление записи

1. Создайте JSON/CSV с полями из таблицы.
2. Укажите открытый источник и лицензию.
3. Импортируйте через вкладку **«Сигнатуры» → Импорт JSON/CSV**.
4. Проверьте матчинг на реальном событии.
5. Для upstream-контрибуции приложите примеры измерений.

## Ограничения

- Региональные распределения частот различаются.
- Открытые данные могут устаревать.
- По ширине и скважности модель дрона не определяется.
- Wi-Fi/Bluetooth могут давать похожие признаки.
