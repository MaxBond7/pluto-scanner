# Model card: Pluto Scanner drone ML

## 1. Модель

| Поле | Значение |
|---|---|
| Название | `pluto-scanner-drone-softmax` |
| Версия | `1` (внутри файла модели) |
| Версия приложения | `0.13.0` |
| Тип | softmax-регрессия на 12 признаках IQ |
| Файл по умолчанию | `assets/ml_model_default.json` |
| SHA256 | `a46eff390bcfe3f1ef144f49c5fcdb0383986692981b3052ef86559ee68211e8` |
| Лицензия весов | MIT (сгенерированы из MIT-кода и синтетики) |
| Вход | признаки `DroneObservation`, не сырой IQ |
| Выход | top-3 класса + вероятность |

Классы: `FHSS`, `TELEMETRY`, `VIDEO_ANALOG`, `VIDEO_DIGITAL`, `WIFI`,
`NARROW`.

## 2. Назначение

Модель даёт **вторую гипотезу** к эвристическому классификатору
дрон-монитора. Она не заменяет эвристику, не поднимает тревогу сама и не
декодирует протокол.

Использовать можно:

- как подсказку в карточке события;
- для сравнения с эвристикой;
- как baseline для локального дообучения.

Нельзя использовать как:

- единственный детектор;
- доказательство модели дрона;
- Remote ID;
- средство определения дальности/направления;
- сертифицированное средство безопасности.

## 3. Данные обучения

Обучение только на **синтетическом IQ**, сгенерированном кодом проекта:

- 60 блоков на класс, 360 блоков;
- генератор: `pluto_scanner/ml/synthetic.py`;
- seed `1`;
- 600 эпох, Adam, L2 `1e-3`;
- train/test split стратифицированный, 20% test.

Сторонние датасеты в обучение **не входили**. Это важно: модель не содержит
данных DroneRF/DroneDetect/CC BY-NC.

## 4. Метрики

### Отложенная синтетическая выборка

- accuracy: **94.4%**;
- 72 примера;
- согласие с эвристикой: 25.8%.

### Domain-gap (31.10.2026)

| Домен | N | Accuracy | Confidence |
|---|---:|---:|---:|
| synthetic fresh | 94 | 98.9% | 91.9% |
| synthetic augmented | 89 | 95.5% | 85.6% |
| real Baofeng 433 / NARROW | 11 | **72.7%** | 69.1% |

Реальные ошибки: `NARROW` → `TELEMETRY` (2), `NARROW` → `FHSS` (1).
Подробности: `docs/DOMAIN_GAP.md`.

## 5. Ограничения

- Синтетика ≠ реальный эфир; реальная точность ниже.
- Обучена только на одном генераторе и одном наборе параметров.
- Не видела реальных Wi-Fi/Bluetooth/FPV-записей.
- Чувствительна к перегрузке входа; перегрузка отсекается отдельным
  правилом.
- Не учитывает антенну, усиление, кабель и многолучёвость.
- Не является определителем модели дрона.
- Не заменяет Remote ID.

## 6. Риски и смещения

- **Domain gap**: реальные сигналы «грязнее» синтетики.
- **Overconfidence**: высокие вероятности на синтетике не гарантируют
  реальную уверенность.
- **Label bias**: классы заданы эвристикой/синтетикой, а не экспертной
  разметкой.
- **Front-end overload**: мощный сигнал вблизи может выглядеть как FHSS;
  исправлено флагом `OVERLOAD`.
- **Environment bias**: один город/антенна/усиление.

## 7. Проверка и воспроизведение

```powershell
python -m pluto_scanner.ml.train --per-class 60 --epochs 600
python -m pluto_scanner.ml.domain_gap
python -m pluto_scanner --domain-gap
```

Модель по умолчанию проверяется тестом `test_bundled_default_model_loads`.

## 8. Обновление

- Пользовательская модель: `user_data/ml_model.json` имеет приоритет.
- Встроенная модель обновляется вместе с приложением.
- При несовместимости признаков приложение откатывается на встроенную.
- Новая модель должна сопровождаться обновлением этого файла и
  `CHANGELOG.md`.
