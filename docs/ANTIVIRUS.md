# Антивирус и ложные срабатывания

## Коротко

Windows Defender иногда удаляет `PlutoScanner.exe`, portable-сборку и
установщик. Это **ложное срабатывание**, а не вирус. Причина — неподписанный
исполняемый файл без репутации, собранный PyInstaller.

## Почему это происходит

1. **Файл не подписан.** Windows видит «неизвестного издателя». У подписанных
   программ есть имя, которое можно проверить; у нас его нет.
2. **PyInstaller.** Загрузчик + встроенный Python + набор DLL — очень
   характерный шаблон. Именно на такие шаблоны заточены ML-эвристики
   (`Trojan:Win32/Wacatac.B!ml`, `Wacapew` и подобные). Настоящего кода
   вредоносной программы в файле нет, эвристика смотрит на форму.
3. **Нулевая репутация в облаке Microsoft.** Файл новый, его скачали
   единицы. Для облачной защиты это подозрительно само по себе.
4. **Mark-of-the-Web.** ZIP, скачанный из интернета, получает метку. После
   распаковки она остаётся на `.exe`, и SmartScreen считает файл
   «из интернета, издатель неизвестен».
5. **Приложение работает с USB и сетевыми сокетами.** Для SDR это
   нормально, но поведенчески выглядит «серьёзно».

### Что проверено и не является причиной

- UPX **не используется** (`upx=False` в spec);
- сборка **one-folder**, а не самораспаковывающийся one-file;
- **нет запроса прав администратора** (стандартный манифест `asInvoker`);
- установщик ставит программу **в профиль пользователя**
  (`PrivilegesRequired=lowest`);
- нет автозапуска, нет телеметрии, нет обращений наружу.

## Как убедиться, что файл не подменён

В каждом релизе есть `SHA256SUMS.txt`:

```powershell
Get-FileHash .\PlutoScanner-Setup-0.14.2.exe -Algorithm SHA256
```

Хеш должен совпасть с тем, что в файле.

## Что делать

### 1. Разрешить локально (быстро, антивирус не отключается)

Параметры → Конфиденциальность и защита → Безопасность Windows → Защита от
вирусов и угроз → Исключения → добавить папку с программой.

Или из PowerShell с правами администратора:

```powershell
Add-MpPreference -ExclusionPath "C:\Users\Вы\AppData\Local\PlutoScanner"
Add-MpPreference -ExclusionPath "C:\путь\к\PlutoScanner"
```

### 2. Отправить в Microsoft как ложное срабатывание (правильный путь)

<https://www.microsoft.com/en-us/wdsi/filesubmission>

- выбрать «Software developer»;
- загрузить `PlutoScanner.exe` (или установщик);
- отметить «Incorrectly detected as malware».

Обычно проверка занимает 1–3 дня. После этого файл перестают удалять у всех,
а не только на одной машине.

Текст заявки:

```text
Pluto Scanner is an open-source (MIT) passive SDR receiver for the ADALM-PLUTO.
The binary is built with PyInstaller from https://github.com/MaxBond7/pluto-scanner
and is not code-signed yet. It contains no packer, no persistence, no telemetry
and no network calls; it only reads USB SDR samples and displays a spectrum.
The detection looks like a generic PyInstaller heuristic. Please re-check.
SHA256: <вставить из SHA256SUMS.txt>
```

### 3. Подпись кода (единственное постоянное решение)

Пока файл не подписан, эвристика может срабатывать снова после каждой
пересборки. Варианты:

- сертификат подписи кода OV/EV;
- Azure Trusted Signing (для физлиц; доступность зависит от страны);
- SignPath — бесплатная подпись для open-source проектов.

После подписи SmartScreen доверяет издателю, а не эвристике. Пока репутация
не накопилась, предупреждение SmartScreen может остаться, но **удалять**
файл перестают.

## Что уже сделано в проекте

- UPX выключен;
- сборка one-folder;
- без прав администратора;
- версия в ресурсе `.exe` теперь генерируется из `pyproject.toml` при каждой
  сборке (раньше застревала на 0.13.0 — это выглядело как «старый файл»);
- `SHA256SUMS.txt` в каждом релизе;
- сборка воспроизводима из исходников.

## Если антивирус всё равно удаляет

Пришлите:

1. точное имя обнаружения (Безопасность Windows → Журнал защиты →
   последнее обнаружение);
2. версию сигнатур;
3. какой именно файл удалён: `PlutoScanner.exe`, `Setup`, `ZIP`.

По имени обнаружения видно семейство эвристики, и можно проверить
точечно.
