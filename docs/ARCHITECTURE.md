# Архитектура

## Слои

```text
IQ (Pluto / симулятор)
  -> DeviceSession
     -> SpectrumAnalyzer -> detector -> tracker -> contacts
     -> VFO -> demod -> audio
     -> iq_ready (дрон-монитор)

Сканер:
  ScanController -> peaks -> ScanRecorder -> compare

Дрон-монитор:
  DroneWatchController -> features -> DroneTracker
  DroneMonitorManager -> события, тревоги, IQ-клипы, JSON

Библиотека:
  SignatureStore (SQLite) + seed -> match_event -> top-3
```

## Потоки

- Один `QThread` на устройство; worker только читает IQ.
- DSP, трекер, UI и запись работают в главном потоке.
- Медленный USB не блокирует отрисовку, а зависший GUI не меняет тайминг IQ.
- Сканер и дрон-монитор используют один `DeviceSession`, но не работают
  одновременно: при старте одного режима второй останавливается.

## Данные

| Путь | Назначение |
|---|---|
| `scan_logs/scan_*/` | шаги свипа, фон, отчёт сравнения |
| `drone_logs/drone_*/` | события, `summary.json`, `clips/*.cf32` |
| `user_data/known_contacts.json` | известные контакты |
| `user_data/signatures.db` | локальная библиотека сигнатур |

`scan_logs`, `drone_logs` и `user_data` исключены из Git.

## Режимы

### Сканер диапазона

- Полный пассивный свип 325 МГц – 3.8 ГГц.
- Шаг ~0.8 полосы захвата.
- На шаг — два свежих кадра, средний PSD.
- Пики относительно медианы PSD; спур LO вырезается.
- Фон и сравнение — по пикам и max-hold, только по пересечению диапазонов.

### Дрон-монитор

- Полосы 433/868/915 МГц, 1.2–1.3 / 2.4 / 5.8 ГГц.
- Широкие куски; 10.24 / 20.48 / 30.72 MS/s.
- Признаки: ширина, скважность, импульсы, flatness, SNR, hop.
- Классы: FHSS, TELEMETRY, VIDEO_ANALOG, VIDEO_DIGITAL, WIFI, NARROW,
  UNKNOWN.
- Тревога только после N подтверждений и порога уверенности.
- IQ-клип ~20 мс на событие; лимит 100 клипов за сессию.

### Библиотека сигнатур

- SQLite + встроенный seed.
- Матчинг по диапазону, ширине, скважности, классу и hop.
- Результат — гипотеза с score, причинами и ссылкой.
- Модель дрона не определяется формой спектра.
