# Сборка для Windows

Цель: пользователь скачивает архив, распаковывает и запускает
`PlutoScanner.exe` без Python и без терминала.

## Что уже работает: portable one-folder

```text
dist/PlutoScanner/
  PlutoScanner.exe
  _internal/
    assets/pluto_scanner.ico
    libiio.dll, libiio1.dll, libusb-1.0.dll, ...
    PySide6, numpy, scipy, pyqtgraph, sounddevice, pyadi-iio
```

Сборка:

```powershell
.\build_windows.ps1
```

Или вручную:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller packaging\pluto_scanner.spec --noconfirm
```

Результат: `dist\PlutoScanner\PlutoScanner.exe`.

Особенности:

- `--onedir` (one-folder): быстрый старт, предсказуемая работа Qt и libiio;
- иконка и версия `0.3.0` в свойствах `.exe`;
- `libiio.dll`, `libiio1.dll` и их зависимости (`libusb-1.0.dll`,
  `libserialport.dll`, `libxml2.dll`, `libzstd.dll`) кладутся внутрь
  `_internal`, чтобы сборка работала на машине без установленного libiio;
- `user_data/`, `scan_logs/`, `drone_logs/` создаются **рядом с `.exe`**;
- при фатальной ошибке старта рядом появляется `pluto_scanner_error.log`
  и окно с сообщением.

Проверено на этой машине:

- симулятор: окно, спектр, водопад, контакты — работает;
- реальный Pluto+ по USB (`usb:1.17.5`): захват IQ и живой спектр
  на 433.92 МГц — работает;
- сканер из сборки: 433.0–434.2 МГц, 2 шага, 8 пиков, `background.json`
  рядом с `.exe` — работает;
- дрон-монитор из сборки: полоса 2.4 ГГц, 23 события, 1 подтверждённая
  тревога, 23 IQ-фрагмента — работает;
- распакованный portable ZIP запускается и создаёт `user_data` рядом
  с `.exe`;
- размер one-folder: около 237 МБ, 423 файла;
- время сборки: около 45 секунд.

Готовые артефакты:

```text
dist/PlutoScanner/                     распакованная сборка
dist/PlutoScanner-0.3.0-portable.zip   архив для передачи
dist/SHA256SUMS.txt                    контрольная сумма
```

## Требования к чистой Windows

- Windows 10/11 x64.
- Драйвер PlutoSDR (WinUSB/libusb) для USB-подключения. Без него
  приложение запустится, но плату не увидит; сетевой Pluto работает
  через `ip:192.168.2.1` без USB-драйвера.
- Microsoft Visual C++ Runtime (UCRT) — есть в Windows 10/11; основные
  DLL дополнительно включены в сборку.
- Антивирус может проверить новый неподписанный `.exe` при первом
  запуске. Это ожидаемо; для массовой раздачи нужна подпись кода.

## Ограничения

- One-folder нельзя запускать «из архива» — сначала распаковать.
- Папку `_internal` нельзя переименовывать или удалять по частям.
- При обновлении заменять всю папку `PlutoScanner`, сохраняя
  `user_data/`, `scan_logs/` и `drone_logs/`.
- `pyadi-iio` и libiio требуют совместимый драйвер Pluto; на Linux/macOS
  сборка не проверялась.
