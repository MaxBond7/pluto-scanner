# Сборка для Windows

Цель: одна команда собирает portable-версию, ZIP, контрольные суммы и
установщик. Пользователю не нужен Python или терминал.

## Быстрая сборка

```powershell
.\build_windows.ps1 -Clean -Installer
```

Скрипт:

1. сверяет версии `pyproject.toml`, `pluto_scanner/__init__.py` и сборки;
2. запускает тесты;
3. собирает one-folder через PyInstaller;
4. добавляет `portable.flag`, лицензии, README и CHANGELOG;
5. делает portable ZIP и `SHA256SUMS.txt`;
6. при `-Installer` собирает установщик Inno Setup.

Без установщика:

```powershell
.\build_windows.ps1 -Clean
```

Только пересобрать без тестов:

```powershell
.\build_windows.ps1 -SkipTests
```

## Артефакты

```text
dist/PlutoScanner/                          распакованная portable-сборка
dist/PlutoScanner-<version>-portable.zip    архив для передачи
dist/PlutoScanner-Setup-<version>.exe       установщик (с -Installer)
dist/SHA256SUMS.txt                         SHA256 всех артефактов
```

Внутри one-folder:

```text
PlutoScanner.exe
portable.flag
LICENSE.txt
THIRD_PARTY_NOTICES.md
README.md
CHANGELOG.md
_internal/
  assets/pluto_scanner.ico
  libiio.dll, libiio1.dll, libusb-1.0.dll, ...
  PySide6, numpy, scipy, pyqtgraph, sounddevice, pyadi-iio
```

## Где хранятся данные

| Режим | Данные | Определение |
|---|---|---|
| Исходники | `NEW/` | запуск через Python |
| Portable | рядом с `.exe` | есть `portable.flag` или `user_data/` |
| Установленная версия | `%LOCALAPPDATA%\PlutoScanner` | нет `portable.flag` |

В папке данных:

```text
user_data/       контакты, сигнатуры, белый список, профили фона
iq_recordings/   длинные записи IQ
scan_logs/       свипы
drone_logs/      события и клипы
pluto_scanner.log
```

Переменная `PLUTO_SCANNER_DATA_DIR` переопределяет папку данных — удобно
для тестов и нескольких профилей.

## Установщик

Шаблон: `installer/pluto_scanner.iss`.

- установка per-user в `%LOCALAPPDATA%\Programs\Pluto Scanner`;
- ярлыки в меню «Пуск» и, по желанию, на рабочем столе;
- пункт удаления;
- `portable.flag` исключён из установки, поэтому данные идут в
  `%LOCALAPPDATA%\PlutoScanner`;
- при удалении пользовательские данные не стираются.

Inno Setup 6 можно поставить через:

```powershell
winget install --id JRSoftware.InnoSetup -e
```

Если `ISCC.exe` не найден, `-Installer` только предупреждает и собирает
portable-артефакты.

## Проверено на этой машине

- симулятор: окно, спектр, водопад, контакты;
- реальный Pluto+ по USB: захват IQ и живой спектр на 433.92 МГц;
- сканер: 433.0–434.2 МГц, 2 шага, 8 пиков;
- дрон-монитор: 2.4 ГГц, 23 события, 1 подтверждённая тревога;
- запись IQ: 8 с симулятора и 2 с реального Pluto+ на 10.24 MS/s без потерь;
- воспроизведение записи без платы;
- ML: обучение на синтетике, 94.4% на отложенной выборке, модель рядом с `.exe`;
- ML на размеченных записях: разметка, блоки, разделение по записям,
  смешивание с синтетикой;
- portable ZIP: распаковка, запуск, запись и воспроизведение;
- установщик: установка, запуск, удаление (проверено в 0.10.0);
- установленная версия пишет данные в `%LOCALAPPDATA%\PlutoScanner`,
  установочная папка остаётся чистой;
- при удалении пользовательские данные сохраняются;
- portable-версия пишет данные рядом с `.exe` и не создаёт папку в
  `%LOCALAPPDATA%`;
- размер one-folder: около 248 МБ;
- время сборки: около 45 секунд без установщика.

## Требования к чистой Windows

- Windows 10/11 x64.
- Драйвер PlutoSDR (WinUSB/libusb) для USB. Без него приложение
  запустится, но плату не увидит; сетевой Pluto работает через
  `ip:192.168.2.1`.
- Microsoft Visual C++ Runtime (UCRT) — есть в Windows 10/11; основные
  DLL дополнительно включены.
- Антивирус может проверить неподписанный `.exe` при первом запуске.
  Для массовой раздачи нужна подпись кода.

## Ограничения

- One-folder нельзя запускать «из архива» — сначала распаковать.
- Папку `_internal` нельзя переименовывать или удалять по частям.
- При обновлении portable-версии заменять всю папку, сохраняя данные.
- Установщик per-user; для all-users нужен отдельный сценарий и права
  администратора.
- `pyadi-iio` и libiio требуют совместимый драйвер Pluto; Linux/macOS
  не проверялись.
